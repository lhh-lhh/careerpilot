# GitHub 整理与发布说明

本次操作仅整理和发布现有项目，不继续开发功能，不变更 AI 调用、业务服务、权限或数据结构。

## 范围

- 发布当前工作区的源码与最终界面资源，包括此前尚未提交的工作台补全文件。
- 保留 `src/`、`server/`、`public/`、`tests/`、`scripts/`、`gateway/`、设计和验收文档、PPT 设计材料。
- 归档最终目录导航版 PPTX、演讲稿及现有编辑源。
- 原始课程资料与旧冻结应用不重复上传；需求/设计原始基线已包含在 `docs/baseline/`。
- 重复 ZIP、临时文件、依赖、构建缓存、实际数据库、账号密码表与密钥不上传。克隆后按 README 安装依赖并构建。

## 与原目录关系

发布副本是独立仓库，原运行目录及原 Git 提交不改写。使用新的发布根提交，不推送未经完整审查的旧本地 Git 历史。文件清单与 SHA256 见本目录 `publication-files.json`。

原 README 作为历史参考归档到 [history/README-before-github.md](history/README-before-github.md)；其中相对路径按原根目录书写，需结合当前根 README 导航阅读。历史阶段的三态 AI、早期验收状态和素材描述不得覆盖当前实际实现。

## 验证方法与限制

本次发布记录会单列实际执行的类型检查、Lint、构建、单元测试及仓库扫描结果，不将历史结果冒充新执行。不会运行真实付费 AI 探测，不修改当前账号数据库，不新增公网部署。

发布文件扫描结合禁止路径、常见密钥格式和原本机账号表中的密码进行本地检查；同时检查 PPTX 内可解压 XML/关系文件。检查不向日志输出秘密，也不等于专业安全审计。远程仓库默认 private；未来公开前仍需复审个人信息、图片、文档和许可。

本次整理不会证明真人语音听感、全部设备、生产负载或公网合规已经通过。以 README 与各阶段证据明确注明的范围为准。
