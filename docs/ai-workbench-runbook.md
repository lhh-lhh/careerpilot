# AI求职工作台：运行与现场验收

> 2026-11-15严格AI改造已覆盖本说明的早期行为，最新以[严格AI与pet使用说明](strict-ai-pet-runbook.md)和[验收证据](evidence/strict-ai-pet.md)为准。AI不再回退预设内容；基础岗位推荐也需要真实模型调用；OCR现已接入。旧阶段测试数保留为历史，不作为新范围结论。

本轮为本机在线候选版，承接第五阶段。实现按 DeepSeek 官方聊天、Search、TTS、ASR 指南分工：模型负责语言生成，Search只发现公开资料，应用负责权限、业务校验、保存和评分汇总。不是公网生产放行。

## 启动与配置

在项目根目录使用 Node 24：`npm run build`，再 `npm start`；访问 http://127.0.0.1:4174/ 。使用原账号、原密码，不要重新运行初始化。服务已启动时不要另起同端口服务。替换构建前先关闭自己的服务，保留数据库，再启动完整新版本并刷新页面。

实际库为 `server-data/service.sqlite`。本轮启动前一致性备份位于 `server-backups/pre-workbench-20261115-1340`，带清单；备份之后的用户写入不在该快照内。沿用schema4，workbench记录/额度表以幂等建表创建，不更改原账号密码。恢复请按原备份手册操作到全新目录，不覆盖当前库。

密钥保存于项目外 `%LOCALAPPDATA%/CareerPilot/deepseek.key.dpapi`，Windows CurrentUser DPAPI加密；只可由当前Windows用户解密。服务端加载，不进入浏览器、源码包、日志或实际业务库。另一台电脑需单独配置。`scripts/configure-deepseek.ps1` 的写入模式从标准输入读取到EOF，没有交互提示；轮换时由本机受控程序通过stdin供给，不把明文放在命令参数或脚本文件。**不要直接执行带 `-Read` 的命令或把明文输出给他人**。环境变量 `CAREERPILOT_DEEPSEEK_API_KEY` 可覆盖，不要写进仓库。

当前CLI：存在可用密钥时自动启用，`CAREERPILOT_AI_ENABLED=false` 可关闭；不再要求旧版 `CAREERPILOT_AI_COST_APPROVED`。默认 `deepseek-flash`、共享全局100次/UTC日、每用户40次/UTC日；可用 `CAREERPILOT_AI_DAILY_GLOBAL_CALLS`、`CAREERPILOT_AI_DAILY_USER_CALLS` 配置1..10000整数。新旧AI网关共享调用次数计数，非货币账单预算。工具调用也占次数，失败尝试不退还；无自动付费重试。独立验收脚本使用临时库计数，不计入实际服务库额度，但仍真实消耗供应商余额。

## 建议现场演示（学生账号）

1. 简历工作台填写真实事实并保存 → “AI优化” → 点击生成 → 分部分采纳/全部采纳 → 撤销/手改 → 确认保存一次。保存前正式简历不变，历史恢复先载入草稿，再新增版本。
2. 岗位页面 → AI岗位匹配 → 输入岗位/城市/薪资意愿 → 点击后调用DeepSeek生成推荐顺序和理由，可能产生费用；联网发现另调用Search。规则事实分与AI建议分开，未知资料不当作已满足。打开结果页只读历史，不自动付费。
3. 结果中的“针对此岗位练习面试” → 核实岗位要求 → 点击进入房间。首次现场建议关闭“自然轮换”，核对转写后手动提交；也可开启自动播题/收音、停顿识别和2秒后自动提交。
4. 回答至少一轮 → 结束 → 查看引用依据、逐轮AI参考分和综合报告。未获得有效评价的轮次不记0分。历史记录可继续/查看/删除。
5. 任意业务页打开右下角助手 → 提问并发送 → 跨页保留会话 → 停止/新对话/删除。助手只解释和导航，不执行投递、审批、保存等动作。

AI默认授权按用户要求开启，点击功能才调用，不因打开页面自动付费。顶部“AI已开启/关闭”为本页会话内共享开关；关闭会取消未完成请求，刷新页面恢复默认开启。外发必要资料和费用提示保留，平台额度及服务端consent校验不变。保存简历、投递、签约和删除的业务确认仍保留。

语音须HTTPS或localhost、安全上下文、可用麦克风和浏览器授权。音频16kHz单声道16bit WAV，最长120秒/8MiB，ASR整段上传；TTS返回24kHz PCM逐段播放。暂停、离开、关闭顶部AI授权会停止本地录音/播放并取消未完成请求；已发送数据无法撤回，已保存记录需显式删除。音频不写入平台磁盘，但会发送供应商；不承诺供应商零留存。首次播放可能受浏览器策略限制，可点击重播或用文字降级。

## 接口与安全边界

所有接口为同源 `/api/workbench`，沿用approved账号、CSRF、归属校验；后端重建权限内上下文，不相信前端注入的简历事实。

| 接口 | 用途 |
| --- | --- |
| `GET /status` | 可用状态及次数限制，无密钥 |
| `POST /generate` | 仅`kind:resume`，来源revision和授权校验 |
| `GET/POST /matches`、`POST /matches/analyze` | 保存结果快照、意愿匹配、明确授权的Search/AI分析 |
| `POST /chat`、`GET /conversations[/:id]`、`DELETE /conversations/:id` | SSE对话、本人历史和删除 |
| `POST /speech/tts`、`POST /speech/asr` | 明确授权的语音转换 |
| `POST /documents/ocr` | 明确整份文件外发授权，PDF/PNG/JPEG逐页识别，不自动保存 |
| `GET/POST /sessions`、`GET/POST/DELETE /sessions/:id` | 本人面试记录；answer/next要求授权和revision，complete不触发模型 |

后端限制上游地址、超时、并发、次数、输出token、结构与引用。回答在等待生成下一题和评分前持久保存；出错不捏造分数。日志不保存密钥/原始上游正文。`records.audit`仅提供变更和请求标识，不是完整合规调用审计。自动脱敏不是匿名化保证：自由文本、音频仍可能含隐私，外发前需自行核对。

## 已验证与待验证

最新命令与结果见 [本轮证据](evidence/ai-workbench-progress.md)。真实合成材料探测7项成功：TTS、ASR、提问、评分引用校验、流式对话、简历结构校验、Search；每项一次，无自动重试。它们不等于真人整场端到端验收。浏览器自动测试使用隔离库、合成供应商与假麦克风，不访问物理麦克风、不污染实际账号。

明确边界：

- OCR已接入并限制2MiB/20页；Fetch仍未接入，不声称任意URL抓取可用。
- 非流式ASR、非双工通话；追问和评分串行返回，真实弱网等待、物理设备兼容、回声和听感未验收。
- 简历自动采纳范围仅项目/实习描述；教育、技能、日期等事实字段在原工作台核实。规则能拦截部分新增事实，不能保证模型不编造。
- 助手自动上下文为当前页面路径、角色与权限内简历摘要；未自动附加当前未保存优化草稿或指定报告全文。解释这些内容时请提供必要的脱敏片段，不能假装助手已读取。
- 评分为练习参考，允许1–6维有效返回，不保证固定五维或专业测评效度，不用于招聘决策。
- Search结果不自动成为站内已审核岗位；原来源同步冷却和审核规则不变。
- 本轮未重做生产负载、完整无障碍或真人演示彩排；历史通过结果不能替代新范围验收。

现场最终放行仍需用户本人做一次短语音练习，核对录音→转写→追问→报告的听感与等待。密钥曾出现在聊天，正式发布或共享前请在DeepSeek控制台轮换，并更新本机加密配置。
