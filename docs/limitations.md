## 第二阶段上线前待办

- 当前 Node 24 / SQLite 单进程，JSON 适配表仍需正式查询模型与 PostgreSQL 迁移；没有目标负载、跨设备、TLS、容灾或公网验收。CLI 限本机监听。
- 默认数据与账号均为虚构试用；真实身份导入、组织归属维护、隐私申请和数据留存制度尚未验收。没有注册/找回密码/邮件投递，不显示假成功入口。
- SSE 仅传当前授权账号的空变更信号，重连触发全量授权重读；不是按 Last-Event-ID 逐事件重放消费者。无 IM 或推送送达保证。
- 简历与去向未保存草稿保留在当前页面，外部更新不覆盖，旧版本保存拒绝；刷新/关闭/离开页面仍可能丢弃未保存内容。断线不等于离线编辑队列。提交返回未知时先核对服务端，不盲目重复操作。
- 私有工作区图片会实际解码并裁切重编码、移除元数据；不作为公开学生头像或企业商标。公开组织媒体、内容封面、审核生命周期未纳入本期。
- 独立 AI 校园图首次失败，用户授权延后重试一次已成功，主图接入并保留核验的 CC0 图和缺图占位回退；未切换供应商。概念图不是产品截图。
- 在线使用实际时间，离线使用固定教学时间；毕业届别和去向截止日仍是试用配置，正式运行前须按校历配置。
- 运行中覆盖 dist 会使已打开页面的旧懒加载文件失效；更新应停服务、部署完整构建，再让用户刷新，不能声称支持无缝热发布。
