## 1. 课程原文与项目解释分开

来源：工作区 `web课程原始文件/2026 Web程序设计.html`。提取正文可见：

> 实现一个 Web 应用，要求使用下列技术组合中的一种：
> HTML+CSS+ JavaScript
> HTML+CSS+ React.js 或者 Vue.js

> 每位同学做 8 分钟以内的项目展示，介绍软件的开发背景、概要设计、关键技术和使用方法。
> 验收时间为 12-14 周
> 评价指标包括：项目技术难度、界面美观度、报告演讲水平
> 项目报告电子版（每位同学单独完成，格式为 PDF，文件名为学号）15 周之前发到 ccnu_tuxinhui@163.com 邮箱

本项目正式申报组合② HTML+CSS+Vue.js。TypeScript编译为JavaScript，Vite为构建工具，不改变Vue技术组合；仍需用真实源码、package与生产包举证，当前不是运行证据。

**原生HTML+CSS+JavaScript的原MPA也满足组合①。** 不能说“未用Vue/React所以不合规”，C++后端也不是已明确禁止项。选用Vue是已确定的工程与产品决策，不是强制换框架的课程条款。

原课程正文**没有**“后端可以采用Python”等句子，旧稿将用户允许使用更合理后端语言的讨论混作课程引文，现已纠正。Python/FastAPI是用户方向内的受限AI Gateway选择（v1.5正式接入项），非教师原文授权或课程要求。单框架、无CDN、自研UI、全部本地数值也是项目质量约束，不能伪称课程逐字规定。课程未给三个指标的具体数值权重。

## 2. 技术组合证据

| 技术 | 定位 | 后续证据 |
|---|---|---|
| Vue 3/HTML/CSS | 正式组合② | SFC模板/样式、Router、package-lock与生产包 |
| TypeScript strict | JS类型检查，构建后为JS | typecheck、构建产物与代码定位 |
| Vite | 构建/开发工具，不是第二个UI框架 | 构建日志、无dev客户端的production包 |
| Router/Pinia/Dexie/ECharts/Ajv | 路由/状态/存储/图表/校验库，不是另一套页面框架 | 本地依赖和许可证清单；不能说dependencies只有vue |
| IndexedDB/Worker | 浏览器原生持久化与异步能力 | 刷新持久化、Worker/取消测试 |
| 本地Node启动器 | 必需的静态HTTP文件服务，非SSR/业务后端 | 4173启动、MIME/404/路径安全、离线首开 |
| FastAPI | 必做DeepSeek真实接入网关，离线模式不启动 | GW01–GW12；真实SSE/配对/限流证据，Key不进入前端 |

默认dist使用本机HTTP，不能写file托管/零运行依赖。演示只需预装Node和浏览器，不需要Python/C++编译或外网；不得临时npx下载静态服务器。没有API Key也可运行全部MVP；REPLAY须如实展示MODEL/RULE/CURATED来源。
