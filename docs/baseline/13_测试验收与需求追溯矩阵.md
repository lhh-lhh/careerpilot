## 1. 分层、工具与放行规则

Vitest负责纯函数、Dexie事务（fake-indexeddb）、Provider契约；Playwright负责真实Chromium持久化、路由、Worker、跨角色E2E、打印及无障碍走查。fake-indexeddb不能替代真实浏览器存储测试。网关用pytest/httpx MockTransport验证离线故障边界；只有GW11连接真实供应商，必须用户明确许可。M1锁定依赖、Playwright浏览器及其许可证，之后不依赖临场下载。

未来项目命令固定：`npm run typecheck`、`npm run lint`、`npm run test:unit -- --coverage`、`npm run build`、`npm run test:e2e`、`npm run verify:contracts`、`npm run verify:seed`、`npm run test:perf`、`npm run test:gateway`。test:gateway调用专用venv的`python -m pytest gateway/tests -m "not live"`；GW11为另行许可后执行的`python -m pytest gateway/tests -m live`，默认CI不触发真实调用。命令与工具配置由14实现；本轮未创建这些脚本。生产包测试用本地4173服务，不用dev server代替。

## 2. 测试目录与证据格式

`tests/unit/{matching,resume,interview,lifecycle,metrics,repository,ai}/*.test.ts`，`tests/e2e/{boot,student,company,counselor,admin,offline,privacy}.spec.ts`，`tests/fixtures/{small-domain,ai-valid,ai-invalid,seed-manifest}.json`及`gateway/tests/test_{config,pairing,deepseek,limits,security,live}.py`、`tests/e2e/ai-connection.spec.ts`。夹具从10–12来，不从实际函数反推预期。

每次运行输出 `artifacts/test-evidence/<runId>/manifest.json`：runId、gitCommit、环境（OS/CPU/RAM/浏览器）、schema/seed/algorithm/prompt版本、clock、command、exitCode、caseId、expected、actual、status、artifactPath。状态只允许 passed/failed/not_run/not_enabled；未启用必须有关联范围记录。截图脱敏，HAR/日志不含密钥、原始简历；HTML截图不代替断言。
