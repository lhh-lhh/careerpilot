## 1. 设计语言与视觉方向

**名称**：灯塔 Lighthouse Design。
**隐喻**：就业是一段需要方向的航程；界面像灯塔——**信息清晰、指引明确、不喧哗**。AI 能力用"一束克制的柔光"表达（细渐变条、微光点、流式打字），而不是满屏霓虹发光。

**三条审美准则**：
1. **层级靠留白与字重，不靠边框和色块**。原项目满屏白卡片 + 表格的观感，本质是"没有信息层级"。
2. **每个 AI 结果必须可追溯**（角标 + 依据 + 可驳回），因此视觉上要有统一的"AI 生成"标记语言。
3. **数据优先可视化，表格只在需要精确值时出现**。原项目 32 张表 0 图表，是美观度与应用价值双输的根因。

### 1.1 两套色板（推荐 A，B 为可切换主题）

**A · 浅色学院感（默认，投影仪友好、打印友好）**

| 角色 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 背景 | `--bg-base` | `#F6F8FC` | 页面底 |
| 表面 | `--surface` | `#FFFFFF` | 卡片、面板 |
| 表面次级 | `--surface-2` | `#EEF2F9` | 内嵌区、表头 |
| 主色 | `--brand` | `#2F55C8` | 主按钮、选中态、关键数值 |
| 主色深 | `--brand-700` | `#23409B` | hover / 文字链接 |
| 辅助色 | `--teal` | `#0E9F92` | 完成、成长、正向变化 |
| 强调色 | `--amber` | `#E9A23B` | 提醒、待办 |
| **AI 专属** | `--ai` | `#6E56CF` | AI 徽标、生成内容标记、渐变起点 |
| **AI 渐变** | `--ai-grad` | `linear-gradient(120deg,#6E56CF,#3B82F6)` | 2px 左侧标记条、评分环 |
| 文字主 | `--text-1` | `#16233A` | 标题、正文 |
| 文字次 | `--text-2` | `#5A6782` | 说明、标签 |
| 文字弱 | `--text-3` | `#606D85` | 占位、时间戳 |
| 边框 | `--border` | `#E3E9F2` | 分隔线 |
| 语义图形 | success / warn / danger / info | `#1F9D6B` / `#D9962A` / `#D94848` / `#2E6BE6` | 状态图形；文字另见§11 |

**B · 深色专业感（可切换，用于驾驶舱大屏）**（完整覆盖见§11，以下是概览）：`--bg-base #0E1421`、`--surface #161F31`、`--surface-2 #1E2A40`、`--text-1 #EEF3FC`、`--text-2 #A7B4CC`、`--border #2A3650`；品牌与 AI 色提亮一档（`#5B7CF0` / `#9B87F5`），装饰线条使用；小字号文字另用§11语义色并实测对比度。

> 注：本项目是就业数据而非证券行情，语义色按通用「成功绿 / 危险红」使用，不涉及涨跌红绿惯例。

**图表色序（6 维固定、色盲友好，避免仅靠红绿区分）**：`#2F55C8` `#0E9F92` `#6E56CF` `#E9A23B` `#3B82F6` `#D94848`，配合不同明度与图案（斜纹/点阵）冗余编码。

### 1.2 字体、字号与度量

| 项 | 规范 |
|---|---|
| 中文字族 | `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` |
| 英文/数字 | `Inter, "SF Pro Display", system-ui`；数据表格数字用等宽 `JetBrains Mono` 且 `tabular-nums` |
| 字号阶梯 | 12 / 13 / 14 / 16 / 20 / 24 / 32 / 40 px；正文 14–16，行高 1.6；标题行高 1.25，字重 600–700 |
| 间距基数 | 4 px：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64；卡片内边距 20–24，区块间距 24–32 |
| 圆角 | 6（标签）/ 10（按钮、输入）/ 14（卡片）/ 20（抽屉、大面板）/ 999（胶囊、头像） |
| 阴影 | `--sh-1 0 1px 2px rgba(22,35,58,.06)`；`--sh-2 0 6px 20px rgba(22,35,58,.08)`；`--sh-3 0 16px 40px rgba(22,35,58,.12)`；hover 只升一级，不叠加彩色光晕 |
| 栅格 | 12 栏；内容最大宽 1440；侧栏 240（可收起为 64）；栏间距 24；重点页三栏比 `240 : 1fr : 340` |
| 动效时长 | 120ms（反馈）/ 200ms（状态）/ 320ms（面板、图表入场）；缓动 `cubic-bezier(.2,.8,.2,1)`；`prefers-reduced-motion` 全部降为 0 |

### 1.3 AI 生成内容的统一视觉标记

所有 AI 输出（改写卡、推荐语、评语、预警建议、问数回答）必须带：
① 左侧2px --ai-grad装饰条；② 实际effectiveMode与MODEL/RULE/CURATED来源（12）；③ 底部“请核实·可驳回”，RULE写“本地规则”、CURATED写“人工审校示例”，不可一律写成模型生成；④ 可展开依据与降级原因。
这套标记让"哪些是数据、哪些是模型说的"一眼可辨，既是美观设计也是伦理设计。

## 2. 组件库

### 2.1 基础组件（`components/base/`）

| 组件 | 规格与状态 |
|---|---|
| `AppButton` | primary / secondary / ghost / danger；sm/md/lg；loading / disabled；图标可选 |
| `AppInput` / `AppSelect` / `AppDatePicker` | label + helper + error；focus 环 `--brand` 2px；必填标记 |
| `AppCard` | 标题区 / 正文 / 操作区；可折叠；支持 `--sh-1→2` hover |
| `AppTag` / `StatusPill` | 状态色 + 文字 + 可选圆点；**绝不只用颜色表达状态**（配文字与形状） |
| `AppModal` / `AppDrawer` | 抽屉从右滑入 320ms；焦点陷阱、Esc 关闭、滚动锁定 |
| `AppTable` | 仅用于精确值；斑马纹取消、行 hover、列固定、空态插画 |
| `AppTabs` / `AppSteps` | 下划线指示 / 步骤节点含完成态 |
| `ScoreRing` | 0–100 环形进度，AI 场景用 `--ai-grad`，中心显示分数与变化值 |
| `AppSkeleton` | 骨架屏，形状贴近真实内容；避免整页 spinner |
| `AppToast` / `EmptyState` / `ErrorState` | 统一文案与重试按钮；空态给"下一步做什么"的引导按钮 |
| `AiBadge` / `AiBlock` | 见 §1.3；`AiBlock` 支持流式打字机与"停止生成" |
| `DiffCard` | 改写前（删除线弱色）/ 改写后（高亮）/ 采纳·驳回按钮 |
| `CommandPalette` | P1启用后支持全局Ctrl/Cmd+K，MVP不建伪入口 |
| `ThemeToggle` | 浅/深主题切换，偏好持久化 |

### 2.2 图表组件（`components/charts/`，本地打包 ECharts + 手写 SVG）

`RadarChart`（能力/画像 6–8 维）· `ContributionBar`（A3 六维贡献，可展开到技能命中）· `FunnelChart`（投递转化）· `HeatmapChart`（专业 × 行业）· `TrendLine`（面试成长 / 周趋势）· `DonutChart`（去向结构）· `Timeline`（就业生命周期事件）。

统一约定：图表必须有标题、口径说明、图例、空数据态；数值标签用等宽数字；动画 ≤320ms 且仅入场一次；色序固定；打印时禁用动画并切换高对比配色。

### 2.3 业务组件（`components/business/`）

`ResumeSectionEditor`（可拖拽排序）· `DiagnosisIssueCard`（A1）· `InterviewBubble` + `LiveRubric`（A2）· `JobMatchCard` + `ExplainDrawer` + `WhatIfSlider`（A3）· `AlertRow`（A7 含触发原因展开）· `CitationCard`（A5 可跳原文）· `HelpLoopCard`（帮扶闭环）· `AiRunLogRow`（审计）。

## 6. 状态、动效与反馈规范

| 状态 | 统一处理 |
|---|---|
| 加载 | 骨架屏贴近真实布局；仅 AI 生成用打字机流式；按钮 loading 保留文案 |
| 空 | 插画（几何线条，与品牌一致）+ 一句原因 + **一个明确的下一步按钮** |
| 错误 | 说明发生了什么 + 重试；非取消失败按12降级并显示实际态；RULE失败明确错误和重试，保留数据；用户取消不降级 |
| 成功 | 200ms 轻微高亮 + Toast，不用大幅彩带/弹窗 |
| AI 流式 | 逐字输出、可停止；Provider 角标恒定；生成完成后才出现"采纳/驳回"操作，避免误点 |

**动效清单**：页面进入 fade+8px 上移（200ms）、抽屉右滑（320ms）、图表入场（320ms 一次）、分数环数字滚动（600ms 但可跳过）、hover 阴影升一级（120ms）。
**禁止**：视差滚动、自动轮播、闪烁光效、超过 2 种同时动效、任何阻塞操作的动画、AI 生成时满屏发光。
