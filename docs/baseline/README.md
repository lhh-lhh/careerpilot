## 1. 一页结论

保留原定方向：毕业生就业管理与服务、四角色、就业业务主链、灯塔 Lighthouse Design与品牌“路鸣职引 CareerPilot”（闻鸣知路，循引赴职）。

技术路线仍是Vue 3 + TypeScript strict + Vite，单机Dexie/IndexedDB，默认REPLAY/RULE，Python/FastAPI作为真实AI接入网关，首适配DeepSeek；接入实现与真实验收必做、运行时仍可关闭。MVP仍为A1简历、A2模拟面试、A3可解释匹配、A7就业质量驾驶舱。所有数值本地计算，生成能力只提供受约束文本建议，不替用户提交业务。

v1.5按用户新增确认补齐真实AI接入、独立凭据、统一启动、费用/隐私与四模块真实验收，取代历史D-07“LIVE可不做”的范围；未开始开发。此前已补齐数据字典、独立状态机、幂等/事务/附件、精确算法与指标、AI及回放Schema、全量需求测试追溯、分阶段执行计划；同步修正旧稿合规、来源、评分、降级与范围冲突。详细准入与核验记录见[07](07_开发准入检查清单_DoR.md)。

默认交付不是双击index.html：预装Node，经127.0.0.1:4173本地静态HTTP服务运行，不依赖业务后端、外网或密钥。REPLAY断外网仍可命中；失配才转RULE。取消不触发降级，也不自动付费重试。

## 3. 唯一权威与变更规则

范围以02及13的逐条拆分为准；架构以03为准；字段/状态以10、数值以11、Provider/回放以12及Schema、网关/凭据/启动以15、测试以13、执行依赖以14、视觉以05 §11为准。发现冲突先修文档，不由开发者各自选择旧版本。07负责准入记录，不授权自动启动开发。

FR-S/C/T/A/AI是功能需求；NFR为非功能；A1–A10是能力模块，FR-AI11是跨模块接入需求（不是新增A11能力）；P01–P18是视图族（P02布局、P05b子视图）；D1–D7是实体分组；T1–T6为技术机制编号（T2仅P1）；M0–M5为里程碑；G0–G5为验收门禁；R01–R14为风险。

v1.5是文档版号；schema/seed/algorithm/prompt及gateway的1.0分别管理，不混为同一版本。核心语义变更需登记理由、影响FR/测试/资产版本并同步各册；不得未经用户决策改变品牌、四角色、技术主线或必做范围。

## 4. 来源与诚信边界

可核实依据是课程原始HTML、学校封面、原代码/数据库，以及07已登记的方向决策。08提供路径与来源等级。旧稿无可核验URL的新闻、毕业生规模、政策和院校案例已撤出正式事实论据，本轮不声称核实这些背景材料；新增DeepSeek官方接口页面已只读核对，URL与支持范围见15 §9，不等于真实模型联调。

原生HTML+CSS+JS也满足课程组合①；重构是工程与产品取舍，不是因为C++/MPA被课程禁止。内部决策矩阵权重自定，不冒充教师评分权重。规则分不是招聘能力的科学测评，人工示例不冒充真实模型输出。

品牌中文主名、英文副标及slogan沿用05 §10；正式报告题目为《路鸣职引：面向高校毕业生的 AI 驱动就业管理与智能服务平台的设计与实现》。

完成的是可执行的文档基线和G0检查；未创建careerpilot应用、Git仓库、依赖锁文件、运行种子/回放、组件、Provider、Gateway或正式PDF/PPT。未安装依赖、未调用付费模型。
