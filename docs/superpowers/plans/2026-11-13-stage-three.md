# 第三阶段在线闭环与交付可靠性实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话顺序实施，不委派代理。用户已明确要求按八段讨论及推荐策略继续实施。无HEAD，不创建虚假提交或重置当前目录。

**Goal:** 补齐既有在线候选版的学生邀约办理与恢复能力，为目标部署提供可复验交付证据。

**Architecture:** 保留Vue与领域命令；在既有服务端事务内增加邀约响应。SSE继续最小化信号与授权重读，持久数据库为恢复依据。备份使用SQLite一致性快照和不覆盖式恢复；部署目标未确认前仍只监听本机。

**Tech Stack:** Vue3 / TypeScript / Node24 / SQLite / Vitest / Playwright。

**Spec:** `../../stage-three-traceability.md`、`../../online-upgrade-strategy.md`、`../../role-workspace-assessment.md`（P0/P1及验收第3/8/11项）。

**收口状态：** 下列勾选仅代表本机虚构数据候选版的已实施/已测步骤；不代表整条P0/P1路线或生产放行。最终398单测、110双浏览器功能、6性能及交付副本证据见`../../evidence/stage-three.md`。ZIP最终放行以独立JSON的passed与hash一致为准。外部门禁和未实现专项单列文末，不因勾选而消失。

## Global Constraints

- 冻结目录和`docs/baseline/`不动；保持离线教学版独立。
- 不公网发布、不自动付费AI、不读取真实Key；没有实测不能宣称生产可用。
- 非阻断素材问题登记后继续；安全/数据一致性门禁不延期。
- 使用apply_patch修改文件；新增行为先失败用例再实现，真实HTTP/数据库优先。
