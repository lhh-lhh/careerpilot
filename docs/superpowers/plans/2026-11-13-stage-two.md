# 第二阶段全链条升级实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话顺序实施，不委派代理。用户于 2026-11-13 明确启动此前 D-17—D-21 的延期实施。

**Goal:** 把现有四角色业务接上服务端可信数据边界，交付可本地运行和验证的封闭试用候选版，并落实公共门户、场景识别和说明文字精简。

**Architecture:** 保留 Vue 3 和领域命令；新增 Node 24 / TypeScript 模块化业务服务、HTTP-only 会话、服务端授权和 SQLite 持久事务适配器。浏览器在在线模式只通过同源 HTTP 读取和发命令；离线教学模式保持独立。SQLite 是本机可运行实现，不冒充规划中的 PostgreSQL，后者迁移和部署验收独立记录。服务端时钟覆盖客户端时间。SSE 只传授权用户的变更信号，持久事件可补查。

**Tech Stack:** Vue 3、TypeScript、Node 24 node:sqlite、tsx、Vitest、Playwright；图片遵守 skill-1k。

**执行状态（D-22）：** 下列本机范围已实施并有本轮证据，见 `../../evidence/stage-two.md`。SQLite 和封闭试用边界不变；PostgreSQL/TLS/跨设备/真实身份/真实 AI/负载恢复不在这些勾选的通过范围。源码与 Demo 包另行解压核验，不作公网放行。

## 范围及不变量

- 当前活动目录 `careerpilot/` 是用户指定的新阶段工作位置；冻结目录、原 C++ 和前置文档原件不动。仓库没有初始提交，不能从不存在的 HEAD 创建 worktree；不编造作者或提交。
- 继承公共门户→身份验证→四角色工作区；保留现有品牌及领域算法，不把界面角色选择当身份认证。
- 先构建可测试闭环，再扩展次要模块。预约、招聘会、IM、电子签不因评估表出现就自动纳入本期。
- 不发起付费 DeepSeek；不给前端上游密钥；在线版在安全代理完成前禁止本机 LIVE 网关。
- 不公网发布、不购买服务；真实账号导入、正式数据留存、TLS/部署地域、PostgreSQL 和目标负载仍需实际环境验收。
- 删减重复技术解释和宣传性大页头；保留授权、隐私、不可逆操作、AI 来源、错误恢复、指标口径等必要说明。
