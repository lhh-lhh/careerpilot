# 图文资源层最终设计

北京时间2026-11-18。用户已批准前轮分析并明确授权自主设计、实施、验收，不再设置逐稿确认门槛。属于原全站视觉升级的展示层扩展，不新增业务子系统。

## 方向

保留路鸣职引品牌、九类场景、现有信息架构、全部内容和操作。在背景之上补齐有含义的内容图像：校园到职业的旅程、简历纸面、岗位探索、面试交流、数据洞察、校企协作、服务与安全。采用统一的蓝/青/紫色编辑插画，少量暖橙作为焦点，纸感与柔和立体构成结合；清晰主体、不同构图，避免无意义小图标堆砌。原有企业无可信标识时使用明确的通用建筑图形，绝不制作仿真企业商标或假认证。

## 适配

- 公共门户：现有主视觉保留；服务/准备入口增加主题图，原5个外链、3个准备入口和角色入口数量及目的地不变。
- 页面标题：九类场景分别适配主题图，文字和图片分区而非叠压；桌面横向图文，手机缩小图像但不删除必要文字。
- 岗位：通用企业身份位+岗位事实；数据无logo字段，不改接口或数据模型。名称、薪资、来源、收藏与投递保持。
- 题库：使用主题封面，保留真实题目/说明、文字和语音按钮；图像不是可投递岗位承诺。
- 窗口/导航/状态：使用小幅家族视觉或语义图形，不给长表单和危险确认塞大型海报；主内容、关闭与footer优先。
- 投递/办理历史：紧凑清楚的节点节奏与状态轨迹，不删历史、不重排业务事件。
- 图片中的UI文字仍用HTML，允许少量插画内固有文字但不将整张UI截图作为运行界面。

## 守约

冻结71个既有Vue script和业务区；仅template/style、原生静态媒体及新独立展示样式。不新增依赖、动态请求、自动滚动、AI调用/重试/保存，不变更原route key、事件、条件和model。新媒体默认静态，以有限hover/transition带来动静结合；减少动态关闭反馈，触摸不依赖hover。正文实底，图片不抢事件。深色保留图像原色并有协调容器，打印/强制颜色取消装饰。
