# 路鸣职引 CareerPilot 全站视觉与交互升级最终设计候选 v1.0

日期：2026-11-17。状态：供用户最后确认的施工设计基线；尚未批准执行、未改造应用、未通过运行验收。本文整合本聊天 2026-11-16 18:53 以来及 11-17 的要求与 v0.1/v0.2 材料；本轮核对了聊天记录、现有路由、组件与原设计文档。时间界限是用户指定的讨论范围，不冒称对未提供记录的逐字复原。

## 1. 一句话定案与优先级

在保留现有全部业务、功能、技术栈、权限、数据和 AI 调用契约的前提下，以“灯塔·多场景全站界面”为统一视觉语言，采用强化品牌、可明显感知的全区背景、多层实底内容、统一组件状态和轻量动效，逐页、逐窗口完成 UI/UX 升级。

优先级：P0 业务与 AI 保护和可恢复基线；P1 驾驶舱图表可读性、无效留白/信息层级、授权/连接/任务状态区分；P1 顶部品牌与全站背景显著升级；P2 全角色逐页面/窗口迁移；P3 综合视觉、交互、性能与真实设备验收。P1 优先不代表其余页面可以遗漏。

未选“只加深全局底色”，因为不能体现不同页面任务，也不能修复图表、密度、窗口问题。未选“全屏动态粒子/模板迁移”，因为性能、注意力和生命周期风险高。选定“统一品牌 + 九类场景背景 + 页面族结构 + 逐项运行验收”。

## 2. 不可突破的契约

- Vue 3 / TypeScript / Vue Router / Pinia / 自研 CSS 与组件 / ECharts / Node / SQLite / Dexie 保持；不迁移 React，不引入整套后台工程，不添加第二套路由或状态管理。
- 角色、权限、接口、数据结构、校验、命令幂等、版本/修订冲突、审计、投递快照、附件授权、保存/导出/打印结果、在线/离线分支保持。
- 全部原入口、字段、条件显示、按钮禁用条件、必要信息与风险说明保留。图纸使用合成样例；图中缩略信息不是删字段/删功能授权，设计说明文字不是要求灌入真实页面。
- 禁止将未保存草稿自动保存、将 OCR 自动回填正式简历、用假答案/规则代答冒充真实 AI，禁止因“美观”改变来源或校外跳转语义。
- AI 模型配置、提示词、参数、上下文、外发范围、默认授权、额度、确认票据、重试、取消、超时、输出校验、来源记录不改。状态查询与生成请求分开统计。
- 不修改后端、AI 服务、适配器、契约、领域逻辑、业务 store；前端调用页 script 首轮冻结。确需纯展示 script 差异必须列出路径、最小 diff 与测试证据；涉及业务/生命周期的差异需另获批准。
- 页面进入/滚动/悬停/动画/主题/响应式变换/窗口开合不能额外生成、提交、重试、清空草稿或重建任务。保留 AppShell 当前面试专用 route.path key，禁止扩大为 fullPath、theme 或 viewport key；不添加 out-in 或 KeepAlive 改变生命周期。
- 不读取/迁移/重置真实库、凭据及账号配置；不部署/发布；不自动执行付费 AI、生图、来源同步或云端素材生成。稳定演示版与 docs/baseline 不动。
- 原有技术能力完整保留，但不锁定此前参考评分、不承诺外部 API 永不失败、不在验证前承诺绝对零风险。

## 4. 背景系统：全区可见，不是角落点缀

### 4.1 共同层次

L0：全页主题基底；L1：覆盖主内容区域及长页各分区的场景色面/矢量图形；L2：实底内容、表单、表格、图表/文书；L3：原导航、弹窗、提示、助手与宠物层级。每页主体必须有明确背景色面，长页每个大分区都有连续背景或分段色面，不能只有首屏顶角一块渐变。

L1 使用 CSS linear/radial/conic-gradient、repeating 纹理及本地 SVG 组合；校园图等已有图片为受控内容层，不把同一照片铺满所有页面。背景容器 isolation:isolate，装饰 pointer-events:none，伪元素不进入朗读顺序；使用真实装饰节点时 aria-hidden=true。不得在容纳 fixed/Teleport 的业务祖先上加 transform/filter 改变定位或层叠上下文。

内容表面 opacity=1，不能用父容器 opacity 降低整组文字透明度。浅色次级文字候选从 #5A6782 加深至 #42516C，以适配更明显的色面；输入/风险/来源仍需按实际合成颜色检查。print 去掉装饰，PDF/简历/意向文书保留原白纸与原内容，不能把装饰写入文书。

### 4.2 九类场景

| 家族 | 范围 | 色面与元素 | 变化体现 |
|---|---|---|---|
| campus 校园航线 | 门户、机会、登录注册邀请 | 蓝青宽色带+职业路径+节点，原校园图 | 全首屏/分区贯穿；图片边框与搜索形成层次 |
| journey 生涯旅程 | 学生概览、匹配、投递与办理流程 | 蓝青层次+连续航线/里程节点 | 标题至内容底部；步骤/时间轴清晰，不能冒充真实完成度 |
| paper 纸张层次 | 简历、优化/OCR、报告、预览与文书外围 | 蓝紫宽底+叠纸轮廓 | 全编辑容器背景，表单与正文仍实底 |
| studio 专注声场 | 文字/语音面试、助手与 AI 辅助窗 | 紫蓝色面+静态同心声场 | 覆盖任务工作区；真实电平单独显示，背景不随意假动 |
| pipeline 招聘管线 | 企业概览/岗位/候选/协议/日程 | 青蓝色面+折线管线/节点+轻网格 | 管线区、列表/详情外部形成连续视觉 |
| analytics 数据坐标 | 驾驶舱 | 冷蓝底+坐标网格/折线母题 | 全驾驶舱承托；绘图区实底，不将装饰线误作数据 |
| governance 秩序网格 | 名册/审核/帮扶/账号/准入/来源管理 | 蓝灰青底+规则网格/分栏轮廓 | 审核证据区外均有结构层次；危险项颜色独立 |
| service 服务航标 | 工单、帮助、消息、引导、组件展示/检查 | 蓝青/蓝紫分区+航标圆环/章节标识 | 列表、详情、抽屉头部和空态均有可见处理 |
| status 状态地形 | 404、无权限、异常、空态 | 蓝灰青色面+地形等高线/图标 | 全状态区与原恢复入口；不杜撰数据 |

家族按任务而非仅按角色区分，跨角色同一操作保持一致；同页不混入互不相关的七彩纹理。深色保留不同图形母题，以 #24395C–#194449 为蓝青基底、AI 紫线条，不以降低所有透明度敷衍。

### 4.3 覆盖与合理边界

完整设计映射：`docs/design/ui-refresh-final-2026-11-17/coverage-matrix.md` 与 JSON。共54个已识别页面/分区条目（含1个不激活的历史 H01），43组窗口/展开/全局反馈。它们不是54条独立路由，更不是已经实现或所有状态都已画出的证明。

站内应用可控制的主/子页面、跳转后的同站页面、导航抽屉、按钮菜单、助手、帮助/消息/指引、表单/确认/详情窗、附件/文书外框与全局提示全部纳入。Teleport 到 body 的窗口必须在 AppOverlay 自身配置背景，不能只依赖 AppShell 继承。

站外招聘/国家平台页面、浏览器标签页框架、系统文件选择框、原生 select 展开列表、浏览器 confirm、PDF 内置阅读器工具条不能通过本站 CSS 全部改造。宿主不可控项必须登记，不能计作已换肤，也不能为了统一样式擅自改变跳转/同步确认。W39–W42 保留现有同步 confirm，若用户要求进一步替换，需单独批准并逐分支证明取消/离开/费用确认语义不变；这项例外不豁免其来源页面和本站窗口的升级。

## 5. 页面结构与组件

驾驶舱、简历布局沿用 v0.1 已确认结构：四 KPI、两列宽图、预警独立、热图全宽；简历编辑优先，六段、全部工具、体检/建议与草稿/版本保留。环图图例、漏斗右标签、轴标签、热图零/缺失语义逐个检验。

公共列表保留公共头，不能带入学生侧栏；登录注册使用独立身份页面；企业列表/详情以候选处理为中心；名册审核与管理治理围绕证据与状态；AI 面试保持问题/输入/实际任务优先。页面族结构及保留字段见逐项台账，不复用门户大图覆盖所有工作页。

基础组件 AppButton/Input/Select/Tag/Card/Skeleton/Toast/Overlay/Modal/Drawer/Icon/BrandMark/EntityMark/ThemeToggle 统一升级；组合以稳定标题区、操作栏、筛选/字段组、状态/空态、表格/图表/文书框为单位，已有相同结构优先 CSS 规范，不强行拆组件。首次迁移尽量只改 template 的 class/语义和 style，不搬 handler 或计算逻辑。

按钮保留 primary/secondary/ghost/danger、原尺寸及 loading/disabled/type；44px默认触点、36px紧凑桌面、52px大操作。default/hover/pressed/focus-visible/disabled/loading 都有可区分样式；禁用不只靠很浅文字、加载不引起宽度跳动。图标不替代可读标签，外链箭头不能取代来源提示。

表格有稳定位宽、表头/行分隔、选中标志和局部横滚提示；不自动滚动审核表格。输入标签/帮助/校验邻近，保留原 model/update、IME、原生 select 语义、上传限制与原始错误值。必要说明保留，不把风控与外发警告折叠到不可见角落。

确认480、表单640、对照960、抽屉480px为上限候选，均受视口约束。窗口标题区用场景色带/图形，正文实底，操作区稳定且不遮输入；原滚动、焦点限制/恢复、Esc、mask、busy关闭条件不变。危险确认使用 danger，不统一成品牌蓝。

## 6. 动效、响应式与可访问性

反馈120ms、状态200ms、窗口260ms、首次渐入240ms/≤8px、错峰40ms且总序列≤400ms。持续装饰默认静态；门户可选14–20s局部轻缓动，必须暂停、离屏停止及减少动态静态替代。业务正文默认可见，不依赖观察器才显现，不引入滚轮劫持/强制整屏翻页/无限循环跑马灯。

助手仅在用户已处于底部时沿用/完善跟随，用户向上读历史就停止抢滚，保留“回到最新”；不得修改流式缓冲/安全处理。波形绑定真实电平，没有可测进度就用真实阶段/不定进度，不显示假百分比。宠物全部动作、尺寸、睡眠、暂停、漫游、拖动和键盘行为/许可保留；停靠不自动覆盖用户位置。

覆盖375/390、768、1024、1280、1440、1920px；320 CSS px等效重排、200%缩放、键盘、触摸、软键盘和减少动态。长标题/长公司名/长错误换行，内容自然增长；业务数据不按设计稿固定数量截断。手机导航复用原菜单，无新增业务导航/权限。宽表只局部横滚，文档预览可保留必要二维布局并提供适用说明。

普通文字≥4.5:1，大字/必要边界和焦点≥3:1；不是所有装饰线都要3:1。实际渐变、纹理、叠加、图表和图片上的文字必须运行复核；必要时加实底标签，不让用户为了看背景读不清数据。支持系统强制颜色模式，图表有原 summary/文本替代。

## 8. 验收与执行准入

设计准入：用户确认本候选设计与覆盖边界后才修改应用。实施计划属于待批准施工草案，不等于已经授权业务变更。

视觉：对相同合成数据/同主题/同视口保存旧版、设计、实现三方截图；每个页面/窗口组逐项比对品牌、主体背景、分区、文本、控件与所有入口。背景必须在正常视口下直接可见，不以截图放大或降低显示器亮度才能辨认；不能只在角落或一屏顶部出现。显著变化由用户比较确认，不声称存在普适“美观90分”。

功能：四角色同一隔离数据闭环、权限负测、草稿恢复/冲突、上传预览打印、在线/离线可达性、消息/工单和全部窗口动作，原结果一致。任何新增回归修复或回退，不用视觉收益抵消。

AI：可控 transport 的真实调用代码路径与故障场景验证；进入/滚动/主题/缩放/开窗无新增生成，单次原动作次数不变，取消/超时/失败/过期结果处理不变。OCR整文件、语音麦克风/TTS/ASR、授权关闭、IME、历史来源均验证；模型文本不作逐字比较。真实 DeepSeek/生图验收在独立批准费用后进行。

性能：同机器/生产构建/数据/视口对照，既有 PERF01/02/03 阈值不放宽（匹配p95<300ms、筛选/切路p95<200ms、冷登录p95<1.5s）；新增装饰不形成连续空闲长任务或显著卡顿。具体浏览器与样本附结果，不以一次截图证明性能。
