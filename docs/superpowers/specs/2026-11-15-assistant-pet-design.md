## 范围：完整角色表现，不替换业务后端

使用上游现成透明动画完整呈现角色的发型、服装、身体、鲸尾、表情和动作，而非裁剪用户截图、绘制近似头像、仅用CSS上下晃动假装原动态pet。

尽量保留原项目的表现层：待机、转向、随机小动作、走动、点击回应、悬空拖拽、工作状态、睡眠，以及可选择的动作菜单。仓库动画目录内的全部可用webm进入本地素材包与清单，按需播放；不在页面打开时预载100多个文件。依据上游 `assets/config.jsonc` 分类与状态映射，不把全部动作误作为待机轮播。

不引入上游独立聊天服务、无鉴权本机HTTP服务、桌面Electron运行壳、多宠物账号、余额读取、天气定位、待办、系统通知或原服务商配置。没有用户请求时不自动生成“碎碎念”、不播预设AI回答、不自动付费。这符合“仅改外观，保留助手功能”的边界。

## 组件与责任

- 保留 `src/components/business/GlobalAssistant.vue` 的会话、SSE、历史、停止、新对话、删除确认、安全失败处理和快捷导航。
- 新建独立 `AssistantPetLauncher.vue`，只负责pet媒体、交互状态、位置与菜单，通过 `toggle` 事件控制原面板，消费 `open/busy/responding/error` 等无敏感状态，不请求AI。
- 全局入口仍挂在 `src/App.vue`，不移入某个业务子页；已登录approved账号在应用内跨页面常驻。登录前不暴露带用户数据的助手；登出或换用户时原有会话清理规则不变。
- 将纯位置约束、长按手势和动画状态选择拆到小型可单元测试模块；上游代码如直接复用或改写保留MIT声明。
- 素材位于 `public/vendor/dsh-pet/`，附manifest（原路径、固定commit、SHA256、字节数、分类）及许可证和改造说明。不远程热链，不运行上游安装脚本。

## 动态表现

| 状态 | 表现 | 触发依据 |
| --- | --- | --- |
| 闲置 | 原待机呼吸、按上游分类选小动作/转向 | 本地动画调度，不生成文字 |
| 点击 | 原点击回应，随后开/关原聊天面板 | 用户单击 |
| 长按拖动 | 原悬空拖拽动画、适度挤压反馈 | 约300ms长按后pointermove |
| 等待模型 | 思考冒泡/忙碌点按 | 真实助手请求busy |
| 正在输出 | 对屏/记录类动画 | 实际SSE有文本输出 |
| 成功/错误 | 庆祝/叹气等短动画，随后返回待机 | 当次真实请求完成/失败 |
| 睡眠 | 原开始/循环/起身动画 | 用户动作菜单选择；再次点击可唤醒并使用助手 |

所有动作都是表现状态，不声称模型在决定动作。禁止宠物动画状态显示“已成功”而请求实际失败；没有SSE内容时不播放“已回复”的状态。

“AI Chatbot”采用角色身前/下沿小型清晰铭牌，不遮挡脸和主要服装。另提供简短长按提示与可见焦点框，不把原助手入口藏成难识别的装饰物。

## 移动与面板布局

- 聊天面板关闭时pet照常渲染、动画和接收pointer事件；长按拖动不依赖 `open` 状态。
- 单击打开/关闭；约300ms长按激活拖动，使用pointer capture持续跟踪。拖动或长按释放后抑制合成click，不能误开面板。pointercancel、失焦、组件销毁要清理捕获与计时。
- 鼠标与触屏共用手势；pet本体禁止文本选择与原生媒体拖拽。仅pet占据交互区域，透明画布余白不应挡住大块业务页面。
- 位置以视口坐标记录，限制在可见范围并留安全边距；resize、缩放、移动设备方向变化后重新clamp；页面滚动不把pet滚出视口。
- 本机存储仅包含位置、大小、动画偏好，不含用户资料。坏值、超出范围或存储不可用时安全回到默认位置。
- 提供“回到右下角”、大小与暂停动画/漫游设置；键盘Enter/Space可开关助手，提供键盘移动路径，不要求所有人使用长按。
- 可选慢速漫游只在面板关闭且非拖动时运行，提供关闭；默认不跨屏快速乱跑，不影响用户刚放好的位置。漫游无API调用，不意味着页面业务操作。
- 聊天面板独立定位或根据pet位置智能选择左右/上下；始终限制在视口内。小屏使用固定安全边距的面板，不能因pet在左上角导致输入框或关闭按钮出屏。
- 长按拖动中、打开聊天面板、键盘操作或系统减少动态效果偏好下暂停自主位置移动，防止追着入口点击。

## 媒体与性能

- 上游正式资源为640×360的VP9-alpha webm；按角色实际可见区域校准画布尺寸，不拉伸角色比例，不出现黑底或裁断头发/鲸尾。
- Chrome、Edge为主要验收浏览器，Firefox验证透明能力；Safari不能假定支持webm alpha。若未加入上游MOV兼容资源，则使用有来源署名的完整静态角色回退，并明确Safari动态未支持，不能声称全浏览器动画一致。
- 默认只加载当前/下一段动画；动作切换尽量无白闪。网页不可见或减少动态效果时暂停，重新可见后恢复；媒体失败保留可点击的静态角色及标识。
- 原动画静音播放，遵循浏览器自动播放限制，不引入未经用户开启的声音。
- 所有素材本地化后生成哈希清单；交付包包含素材许可，不把原作者标识删除。

## 验收要求

1. 桌面和390px窄屏，助手未打开时角色完整可见、持续动态，单击能打开原助手。
2. 面板关闭时从至少四个方向长按拖动，pet实时跟随且释放不误触聊天；触屏、取消手势与快速单击行为正确。
3. 拖至四角后打开面板，关闭按钮、消息、输入框和发送按钮都可见且可操作；resize和刷新后入口不会丢失。
4. 跨学生、企业、辅导员、管理员业务页入口常驻；会话和换用户清理行为不变。不得把全局pet仅做在“AI助手页面”。
5. 等待、流式回复、成功、失败、停止状态与真实请求一致；无请求时动画不产生后台模型或工具调用。
6. 默认角色与截图/上游原素材对照，验证完整身体、发型、服装、鲸尾；透明区域不挡业务点击。
7. 动作菜单和各状态选用原动画；全部打包资源可解析、manifest哈希相符；来源/许可可在UI及交付材料查看。
8. 单元测试覆盖长按阈值、误点击抑制、clamp、存储恢复、取消清理及动画优先级；E2E覆盖关闭面板拖动、跨页、窄屏、面板边界、原聊天历史/停止/删除等回归。
9. 浏览器实际观察动画播放、透明效果和拖动，不仅依赖DOM测试；未验证浏览器、物理触摸设备及完整上游功能差异须如实列出。
