# 招聘闭环与体验补充设计

用户于2026-11-15确认：参照真实就业平台，自行完善企业信息，新增企业关联现有学生，再实施附件其余要求。本文件固化已批准方向，不另建用户体验库。

## 范围与原则

1. 当前服务数据库新增 `hr.pilot`，企业“路鸣校招实践企业（试运行）”。企业和岗位显著说明仅用于本机平台招聘流程试运行，不代表工商认证、真实劳动关系或真实就业结果。参照国家大学生就业服务平台的职责、任职条件、城市、薪资、截止时间和风险提示组织信息，不复制或冒用第三方雇主。
2. 关联现有 `student.chen`，只读取已有简历；不替换、补造其履历、证书、学校、联系方式或就业证明。通过真实账户权限、业务命令、持久化、审核和同步推进试运行投递与面试。录用、签约及就业审核仅在明确试运行语境中验证；不得混入真实就业统计。当前模型没有试运行统计隔离字段时，线上停在面试邀约，后续完整签约链在自动化测试库验证并提供操作路径。
3. 保留原五账号、原企业及资料；写实际库前进行SQLite一致性备份。脚本重复运行不得重复建账号、重置密码、重复投递或推进已完成阶段。新随机密码仅保存于被忽略的本机凭据文件，不写源码、文档、日志或交付包。
4. 当前仓库 `develop` 无HEAD，所有既有源文件未跟踪：原位保留式修改，不创建初始提交、worktree或重置。

## 六项交付

### 城市与岗位筛选

统一全国主要城市参考目录，保留已有 `city-1/2/3` 标识与数据。城市筛选、关键词（岗位/企业/JD）、收藏、薪资预设及自定义上下限实时交集筛选。工资单位税前元/月；工资范围按区间相交判断，面议仅在无金额条件或明确选择面议时出现。无条件展示所有可见岗位，不依赖匹配计算是否完成；无简历也可浏览，但投递仍校验简历。空值、负值、非数值或倒置上下限应可理解地提示。真实岗位与外部机会、独立练习模板不混淆。

### 图文导航

中等宽度不再隐藏导航标签，采用约208–240px图文侧栏；窄屏采用可展开抽屉。保留焦点、可访问名称和当前路由高亮，以分组、色彩与空间层次增强识别，不引入新图片或依赖。检查768/1024/1280及移动端无横向溢出。

### 证书附件

证书支持新增、移除、文字说明、PDF/PNG/JPEG上传，单文件沿用2MiB限制。扩展证书可选字段 `description?: string; attachmentIds?: string[]`，旧简历兼容。保留草稿、冲突、版本、撤销和手动保存。服务端验证引用归本人；企业只能下载向本企业投递的固定简历快照中引用的证书文件，不能读取学生其他文件或其他企业申请。展示附件名称、下载与错误反馈，撤下引用不物理删除附件。

### 面试练习

提供前端开发、后端开发、数据分析、产品运营等独立练习模板，含JD、能力要求、示例问题/答题提示与语音练习入口；在没有真实岗位时仍可练习。模板明确非招聘信息，不能投递，不写入jobs。已有真实岗位练习保留。

### 招聘闭环与同步

新增企业走注册→管理员账号批准→企业完善资料→试运行准入审核→企业发岗→管理员岗位审核。岗位至少覆盖前端、数据分析、运营等供筛选与练习参考，资料包含试运行说明。通过企业与既有学生的投递→筛选→面试邀约→学生回应验证两端状态、消息与刷新同步。隔离自动化库验证拒绝、改期、反馈、Offer、接受、双方协议、辅导员审核、备份恢复和越权边界。真实服务不伪造学生资料/就业结果；无法进入投递时明确阻断原因并保留已完成企业与岗位。

### AI默认授权

用户点击生成即调用，不再逐次弹窗/勾选；使用统一默认启用的会话授权状态，可关闭，关闭中止在途生成与录音。保留明确数据外发/费用提示、主动触发、停止、额度、权限、不可变prepare ticket及服务端consent守卫。修改旧业务AI和新工作台全部入口，更新“逐次确认”文案。投递、签约、覆盖简历等业务确认及浏览器麦克风权限不取消，不在页面加载时自动收费调用。
