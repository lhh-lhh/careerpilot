## 3. 三条路线与推荐

| 路线 | 优点 | 局限 |
|---|---|---|
| A 局部添加商标/装饰图 | 成本较低、企业列表变化明显 | 难解决跨页识别、控件比例与布局问题，容易变成贴图补丁 |
| B 统一底层规范 + 按业务语义表达（推荐） | 品牌连续、跨角色可辨认、页面有差异；复用 Vue 资产并分批验证 | 需要资源清单与逐页检查，不能仅靠一份全局 CSS 完成 |
| C 整站重新设计并全部换图 | 改动空间最大 | 风险和返工高，易打断已验证流程，与延续前轮设计的要求不符 |

推荐 B。核心原则：统一的是视觉语法和行为，不是所有页面的构图。新增元素必须能解释“它在识别什么、帮助谁做什么”，没有业务作用就不强加。

## 4. 五类识别元素与适用边界

1. **企业/组织身份**：标志、完整名称、真实行业/城市等必要信息。logo 使用原始比例和适当留白，以 `contain` 放入稳定视觉容器，不强行圆裁。演示企业使用原创虚构标识，始终保留虚构说明；不把示例图中的真实企业商标配给虚构企业。真实企业后续提供有权使用的素材，缺失时稳定回退到名称缩写。
2. **个人身份**：姓名、可选头像和与任务相关的身份字段。头像默认不公开；招聘列表保留中性姓名标记，不因装饰需要新增照片披露或以照片作为候选评价依据。同名者仍依赖有权显示的编号与上下文辨别。
3. **内容/文档身份**：活动或指导可有场景封面；简历、附件、报告以文档类型、名称、版本和状态识别。文件不伪装官方证书，不把锁形图标宣称为真实安全认证。
4. **流程/成长身份**：投递、邀约、协议与审核用有方向的步骤和时间节点，形状、文字和颜色共同表达当前状态；成长路径用于学生引导，审核链用于办理，不能一张“航线图”套全站。
5. **来源/数据身份**：AI 保留 RULE/REPLAY/LIVE 及 MODEL/CURATED/RULE 的准确来源；统计保留口径、范围、时间与一致图例。不得换成 DeepSeek 官方 logo 暗示真实接入成功，也不以光效代表智能可靠性。

平台 `BrandMark` 与以上实体标志分开：平台品牌只在入口、导航与适当页脚稳定出现，不反复作为业务内容的标记。

## 6. 统一布局与组件建议

- 色板、字族、状态色和基础圆角延续 `tokens.css`。新增布局级 token 之前核对现有消费者，不全局降低控件边框对比度或替换冻结规范。
- 页头分“入口叙事”“角色概览”“紧凑办理”三种强度；统一主标题、说明、实体身份、主行动的相对位置，具体信息密度按任务变化。
- 卡片、开放列表、文档面板、数据驾驶舱各有适用边界；同一类面板使用一致分隔/内边距，但不强制所有后台面板都圆角、悬浮或加阴影。
- 品牌标志建议有 32/40/48/64px 的图像槽位，真实素材保留比例与保护空间；头像与功能图标是不同语义，不通过一个万能随机图形组件混为一谈。精确尺寸以视觉稿和代表页面验证后定稿。
- 候选组件为 `EntityMark`（企业身份及稳定回退）、`PersonMark`（中性姓名标记/获授权头像）、`SectionHeader`（强度明确的页头）、`MediaFrame`（封面比例与错误回退）。流程与图表优先完善已有组件，不为每个符号创建新框架。
- 首批本机演示的只读素材映射可按稳定实体 ID 组织，不改企业种子和评分/匹配数据；不能用名称模糊匹配真实商标。真正上传是独立能力，数据库字段、迁移、服务端权限另行设计，不能加一个前端 URL 输入框就声称具备安全在线媒体管理。
- 平台导航与当前页标题一起检查：桌面/平板收起导航仍可辨认，手机有清晰当前页和返回；装饰不成为唯一入口。主动作、标签与小评分都按固有尺寸显示。

## 7. 素材与在线衔接

- AI 位图继续使用用户指定 `skill-1k`；实际生成前读取技能并核对用途、费用与失败状态。本次不生成，不自动重试过去失败/状态不明的请求。
- 可先用原生 SVG 制作虚构企业原创标识和小型语义图形；不生成第三方商标仿品，不把普通行业图标宣称为公司官方标志。摄影/插画按 D-20 核验授权、来源、裁切和实际尺寸。
- 企业标志、内容封面、个人头像有不同的所有者、公开范围和替换权限。网上获取的图片不直接不受控热链；发布前记录来源与许可，必要静态资产随应用交付。
- 后续上传遵循选择/预览/裁切/保存/替换/移除/恢复默认；即时预览与服务器保存明确区分，按权限同步已提交版本。校验、去除定位元数据、压缩、审核、配额、私有下载与缓存失效共同设计。
- 单张图片失败只触发稳定回退，不阻止登录、阅读岗位或办理；名称/状态/按钮始终是原生内容。非首屏懒加载，预留尺寸，主图不过度下载，深色背景保留标志自身色彩。

## 8. 建议实施顺序与范围控制

此处为方向级次序，未开始实施，不代替设计确认后的详细计划。

1. **布局质量底座**：评分字号、按钮/标签拉伸、列表边框、组合搜索、页名与导航层次；先在代表页面验证再扩展同类场景。
2. **识别体系样板**：以企业身份串联学生推荐→岗位→投递/协议，以及企业紧凑工作台；同步补设计系统示例、缺图和深浅主题。
3. **角色逐页扩展**：学生引导/面试情境、辅导员材料/帮扶、治理来源/审计；每页明确“加什么、为什么、不加什么”，保留业务流程和数据真实性。
4. **与既定路线合流**：公共首页按 D-19 独立完成；角色自主媒体按 D-20 与在线权限/存储结合，不暗中提前扩大为完整内容运营系统。

上线部署、多人后端、真实 DeepSeek 调用不属于本次视觉检查已完成范围。视觉改善可以先做，但不能包装成已实现联网协作或真实 AI。
