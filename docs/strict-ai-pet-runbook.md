# 严格DeepSeek与动态pet使用说明

本轮对应北京时间2026-11-15 20:45提出、20:59补充、21:07确认的两份规格。属于本机学习候选版，不是公网生产放行。原账号、密码、岗位、简历、投递及附件保持不变。

## 启动与入口

Node24，先`npm run build`，再`npm run start:online`，访问 http://127.0.0.1:4174/ 。不要运行`init:online`或改密命令。更新后刷新旧标签页；已有有效会话可继续使用。

密钥继续只由服务端读取项目外Windows DPAPI配置或受控环境变量，不能放入浏览器、源码或交付包。新电脑需要单独安全配置。已在聊天中提供过的密钥，公开分享或正式发布前应在DeepSeek控制台轮换。

## AI服务边界

- 表达建议、岗位解释、辅导员问数/帮扶、简历优化、推荐排序、提问和评价、全局对话、Search、OCR、TTS、ASR均通过同源后端调用官方DeepSeek。
- 失败只提示错误；不返回REPLAY/RULE或编造的结果。离线AI不可用。统计、权限、校验、规则分、PDF排版、动画是确定性程序逻辑，不冒称AI。
- 打开页面只读状态或历史，不自动付费；点击生成/发送/开始面试才外发。顶部AI开关可取消未完成请求、录音和播放，但不能撤回已发内容或已产生费用；刷新恢复默认授权开启。
- 默认模型deepseek-flash，共享全局100/用户40次每UTC日；Search、TTS、ASR、OCR及失败尝试也占次数。额度不是金额预算，无自动付费重试。
- 结果可展开DeepSeek凭据：请求时间（本地显示）、模型、平台traceId、实际返回的上游ID和tokens。没有返回的ID/用量不编造。历史时间不是重新生成时间。TTS二进制返回trace响应头。

## 建议验收顺序

1. 简历工作台先保存真实资料，再点“生成表达建议”；右侧并列子页查看原文、建议、采纳/驳回和调用凭据。正式内容不会自动覆盖。独立“AI优化/润色”继续提供草稿、撤销与保存新版本。
2. 岗位匹配→“进行AI岗位匹配”：模型基于最多30个真实候选生成最多15条推荐；未推荐的条目不补造AI理由。规则匹配参考分与AI推荐顺序独立。联网发现增加Search调用，外部链接需原站核验。
3. 模拟面试默认文字模式，岗位化首题、追问与逐轮评价来自模型；文字模式不自动调用TTS/ASR。回答先保存，再等待后续生成。失败不造0分；综合分只平均有效评价。旧规则练习仅保留历史只读，不改称AI报告。
4. 简历工作台→OCR文档识别：每次1个PDF/PNG/JPEG，非空≤2MiB，PDF≤20页。整个文件（包括姓名、联系方式等）会外发，图片不能可靠自动脱敏。显示逐页原文，`length`提示不完整；复制后人工核对，不自动写入简历。离页、撤销授权或清除会移除本页暂存。最长约180秒；取消页面等待不保证供应商停止计费。
5. 任意已登录approved角色页点击pet：原助手聊天、历史、停止、新对话、删除和快捷导航保留，不执行投递/审批/保存。跨页面保留当前会话，换账号/退出清空内存。
6. 语音入口须localhost/HTTPS及麦克风授权。TTS为24kHz PCM，ASR为16kHz单声道16bit整段WAV（≤120秒/8MiB），不是流式识别或双工通话。可核对转写后提交，也可用文字。

## pet操作与许可

单击开关助手；在角色上长按约300ms后移动鼠标实时拖动，关闭聊天时同样可用。松手不误开助手。位置本机保存，越界自动约束。聚焦后方向键移动16px，Enter/Space开关。

“···”或右键打开设置：回到右下角、大小、暂停动画、睡眠、可选慢速漫游、114个原版动作。漫游默认关闭，打开聊天、拖动或减少动态效果时不自动移动；动画不调用模型，不产生API费用。

使用固定提交`572cf0ff68e7ffbe76afe4ba5fd8ae99ec7e0733`的[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，原114段VP9透明动画本地按需播放，不加载上游后端。社区二创，非DeepSeek官方形象。代码MIT，素材CC BY-NC-SA4.0；署名上善无形/ZipZipPipe，须非商业、署名、相同方式共享。商业用途必须另获授权或替换素材。许可文本和哈希在`public/vendor/dsh-pet/`。

Chrome/Edge为主要验收环境。Safari/WebKit使用完整静态角色回退，不保证透明动画；Firefox、物理触屏、真麦克风、听感、弱网和公网容量尚未验收。测试和现场体验边界见[证据](evidence/strict-ai-pet.md)。
