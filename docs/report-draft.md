## 摘要

路鸣职引 CareerPilot 是面向高校毕业生就业服务的本机教学 Web 应用。系统以 Vue 3、TypeScript、Dexie 和确定性领域内核实现学生、企业、辅导员与管理员四角色闭环，并以 RULE、REPLAY、LIVE 三态 Provider 将生成式文本限制在解释与建议层。匹配分数、简历诊断、面试评分和就业指标均由本地算法计算，可复现、可测试、断网可用。

## 1 开发背景与需求

核心问题是把分散的简历、岗位、投递、面试、协议和去向流程组织成可追踪服务，并让智能能力透明、可降级、不过度收集数据。必做能力为 A1 简历改写、A2 模拟面试反馈、A3 岗位解释与 A7 就业质量驾驶舱。

## 2 概要设计

前端采用 hash 路由和 Pinia 会话；业务数据经作用域服务访问 Dexie，不向组件暴露原始数据库。命令包含幂等标识与期望 revision，多表写入在事务内完成。领域状态机和算法为纯 TypeScript，AI Provider 只能写 AiRun，不能修改业务状态。

## 3 关键技术

1. 作用域仓储、revision 冲突、幂等 receipt 与审计投影。
2. 100 岗 Worker 分批匹配、六维贡献解释和无持久化 what-if。
3. JSON Schema 2020-12、RFC 8785 指纹、语义守卫和过期请求取消。
4. 本机 FastAPI 网关的配对、Origin/Host、防重定向、速率、并发和预算限制。
5. ECharts 按需引入与稳定分包；双主题、移动布局、打印和键盘可达性。

## 4 系统实现与界面

学生页面覆盖简历、岗位、投递和模拟面试；企业工作台覆盖岗位至协议；辅导员覆盖去向审核、四图驾驶舱和帮扶；管理台覆盖版本、来源、脱敏审计与复位。实现截图和视觉对照见 `docs/evidence/M4.md`。

## 5 测试与评估

采用 Vitest、fake-indexeddb、Playwright Chromium/Edge 和 pytest。当前准确数字以 `docs/test-results.md` 为准。离线 Demo ZIP 已从解压目录直接启动并验证零外部请求；真实 DeepSeek GW11 因未获费用许可为 `not_run`，不以 stub 冒充。

## 6 总结

项目的重点不是把模型接到每个页面，而是建立“本地数值真相源 + 可验证文本增强 + 明确数据边界”。后续在用户提供身份字段和真实调用许可后，可补 GW11 四模块证据并生成正式课程 PDF。
