## 安装与启动

环境Windows / Node24.19.0 / npm11.17.0，依赖按lock安装：

```powershell
npm ci
npm run typecheck
npm run build
```

已有数据库不要初始化。首次显式初始化，密码文件也须全新：

```powershell
npm run init:online -- --credentials-file "D:/受控目录/全新账号表.json"
npm start
```

密码目录应预先存在且限制访问。默认数据库为 `server-data/service.sqlite`；`npm start` 或双击 `start-service.cmd` 启动127.0.0.1:4174，Ctrl+C停止，不隐式创建业务账号、不重置已有库。`/api/health` 应ok/schema3，`/runtime.js` 为在线标识。CLI仅允许loopback，不通过更换HOST绕过TLS/生产门禁。

`CAREERPILOT_DATABASE` 指定独立绝对路径，`CAREERPILOT_PORT` 指定端口；不要多实例共享同一SQLite库。旧离线教学版仅显式 `npm run start:demo`（4173），不是默认服务入口。服务器以UTC记录时间，日程按北京时间显示。

## 账号办理

1. 学生/企业公开注册待审；账号去空格转小写，密码12–256字符。辅导员/管理员不能公开自选注册。
2. 待审/未通过仅可查看本人状态、改密、退出；业务、附件、图片、SSE和AI由服务器拒绝。
3. 管理员“账号审核”核对学号/院系专业/届别并分配有效辅导员，或核对企业名，填写说明。批准事务建立空档案；企业资质在“准入与辖区”另审。按钮不能代替现实学籍/资质核验。
4. 员工邀请绑定账号和角色，48小时、一次性；链接只显示当次，经可信渠道发送。重签使同账号旧未用链接失效。
5. revision冲突需重新核对；失败保留输入。未通过后的更正当前由就业服务人员人工处理，无自助重提流程。
6. 改密验证旧密码并撤销全部会话。忘记密码由本机操作者核验后 `npm run password:online`；控制台密码输入可见，勿共享屏幕。没有邮件找回、短信或SSO，不宣称已经发送邮件。

持久限流：注册20次/小时/IP；登录8次/15分钟/账号+IP、100次/IP；改密8次/15分钟/账号。成功登录清除账号失败桶；学校NAT可能共同触发IP限制，真实试点前另评估。

## 备份、恢复与升级

```powershell
npm run backup:online -- "D:/受控目录/service.sqlite" "D:/受控备份/全新快照目录"
npm run restore:online -- "D:/受控备份/全新快照目录" "D:/受控备份/全新恢复目录"
```

原生快照包含WAL提交并附SHA256；恢复拒绝覆盖、撤销旧会话，返回新目录 `careerpilot.sqlite`。先停写/保留原库并核对快照后写入损失，再用 `CAREERPILOT_DATABASE` 显式切换，重新登录检查协议/附件/去向/待办。勿运行中仅复制主库。备份含私有业务与密码哈希，必须受控。

schema3增加邀请/限流/规范化账号索引。旧schema2程序不能打开已迁移schema3库；旧库规范化重复账号会拒绝迁移，不自动合并身份。升级前保存旧完整版本及迁移前一致性备份；回滚须停新服务、恢复迁移前快照到新目录并评估后续写入损失，不盲目降级同库。第三阶段回滚测试不是本阶段schema降级证明。

采用独立完整版本目录、停机切换、用户刷新，不覆盖运行中dist。旧页加载失败提示刷新并保留屏幕，不等于无缝热发布。
