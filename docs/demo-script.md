# 路鸣职引 CareerPilot · 7 分 30 秒演示脚本

演示前：使用离线 Demo ZIP；预装 Node 22.12–24.x；断开外网；关闭 4173 占用；双击 `start-demo.cmd`。不现场安装、编译、输入密钥或启动网关。先以管理员复位固定种子，再退出到角色选择。

| 时间 | 操作 | 讲述要点 |
| --- | --- | --- |
| 0:00–0:35 | P01 选择学生 | 四角色共用一套本机作用域服务；数据完全虚构，默认 REPLAY，断网可演 |
| 0:35–1:30 | 学生首页 → 简历 | 首页优先展示下一步；简历本地体检可复现，A1 只生成建议，采纳前对照 before/after/evidence |
