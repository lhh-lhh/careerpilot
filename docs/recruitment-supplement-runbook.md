入口：http://127.0.0.1:4174/ 。Node24，项目根目录`npm start`，已有服务勿重复启动。原5账号和密码保持不变，切勿重新初始化。新企业账号`hr.pilot`，密码只在本机`server-data/pilot-credentials.json`；不要共享凭据、数据库或备份。

## 先体验这六项

1. 学生→岗位匹配：无筛选展示全部已审核岗位。56城、岗位/企业关键词、收藏和薪资组合筛选；自定义支持单边界，单位税前元/月，区间有交集即显示。面议在金额条件下不视为符合。
2. 桌面和平板侧栏图标+文字；手机点击左上导航抽屉，保留当前路由高亮和键盘焦点。
3. 学生→简历工作台→证书：添加证书、文字说明、文件；仅本人真实PDF/PNG/JPEG，每文件2MiB/每证书最多5件。上传后点击“保存新版本”才固定引用；移除引用不物理删除。接收企业只能下载对应投递快照的证书，不可见其他私人文件。
4. 模拟面试→4个练习模板：前端、后端、数据分析、运营。阅读示例问题和提示，可带岗位要求进入语音练习；它们不是可投递职位，不会污染岗位和招聘统计。
5. 企业`hr.pilot`的3个校招试运行岗位已经上架，现有`student.chen`已收藏。企业资料在招聘概览/岗位管理可维护，认证独立于资料编辑；已核准名称不能直接替换身份。
6. AI默认开启，点击生成即调用DeepSeek；顶部可关闭停止未完成请求/录音/播放，刷新恢复默认。打开页面本身不付费；外发内容与费用提示、额度、后端consent及脱敏票据仍保留。业务保存/投递/删除确认和浏览器麦克风权限不取消。

## 现有学生推进路径

早期检查时实际学生教育经历为空；在本轮简历工作台增强前，现有学生已自行完善学校、实习与证书等资料。本轮未修改这些内容，也未代为投递。请本人核对真实学校、专业、学历和日期，保存后再确认投递。不要为了通过验收虚构资料。

在已收藏的前端/数据/运营岗位中核对JD→投递并授权该次快照→企业候选人流程收到简历和消息→筛选/面试安排→学生“我的投递”确认或申请改期→企业确认调整/记录反馈。各角色各自登录，可用两个独立浏览器，登录会话分别保留。SSE使已保存状态同步，未保存草稿不被覆盖。

企业为显著标注的本机试运行主体，非工商认证或真实劳动关系。当前无试运行就业统计隔离字段，实际试运行停于面试邀约；完整Offer→学生接受→双方协议→学生填去向并上传证明→辅导员审核已经临时测试库验证，不应在实际库制造虚假就业。

## 维护与交付

备份路径和实际验收结果见`evidence/recruitment-supplement-progress.md`。一致性备份和恢复继续使用CLI；恢复到全新目录，不直接复制运行中sqlite或删除WAL。`npx tsx scripts/setup-pilot.ts`是本机操作者显式执行的幂等预备脚本：不改原账号密码，不改原简历，不重复开户/投递。本人资料齐备时可走正常命令自动推进首个岗位至面试邀约，启动服务本身不会触发该操作。

运行检查：`npm run test:unit`、`npm run typecheck`、`npm run lint`、`npm run build`、`npm run test:e2e -- --workers=4`，建议依次运行，避免同机并发争抢资源导致用例超时。本轮最终476单测、144双浏览器E2E通过，详情见`evidence/resume-studio.md`。E2E用独立数据和合成AI，不访问真实麦克风或污染实际账号。真实语音听感、网络等待和物理设备仍需本人做一次短练习。当前仅本机候选版，未放行公网。

源码包仅源码/公共资源/测试/说明，不含实际库、备份、密码、API密钥和node_modules。另一台机器解压后`npm ci`、构建、单独初始化自己的新库；实际用户数据只能走受控快照，不随源码包复制。

本轮简历增强最终包：`artifacts/resume-studio-final-20261115/careerpilot-source.zip`。旧`recruitment-supplement-final`包保留，但不含本轮简历增强。AI密钥曾以明文出现在聊天，部署或共享前应在官方控制台轮换，不能把原密钥放入源码包。

## 简历工作台增强：三项入口

1. 证书预览：简历工作台→证书附件缩略图/“点击预览”。PNG/JPEG可放大查看；PDF使用延迟加载的本地PDF.js渲染、上一页/下一页；不依赖浏览器PDF插件，不执行文档脚本/链接。损坏或加密PDF会提示下载原文件。原附件ACL、每文件2MiB、每证书5件均不变。
2. 表达建议：先保存→点击“生成表达建议”→自动打开`/student/resume/suggestions`。桌面左侧编辑、右侧原文/建议对照，手机用“编辑主页面/表达建议子页”切换。每项可采纳/驳回；采纳创建新版本，剩余旧建议需要重新生成。生成进度/错误/无结果均在子页显示，刷新不会自动付费重试。
3. 简历导出：先保存→“预览与导出简历”→“一键导出PDF”。蓝白双栏A4模板自动分页，全部在本机处理、不调用AI。姓名和完整教育经历未填时禁止导出。PDF为高清图片式版式文件，文字不可选取，不保证站外ATS自动解析；站外上传由本人完成。

站内投递不要求先下载或上传PDF：在岗位页确认授权时可直接看到同款卡片，提交后由系统固定投递快照；学生“我的投递”和企业“候选人流程”均可展开该快照卡片并导出。学生后续编辑不会覆盖旧投递；企业联系邮箱继续按原规则脱敏，证书只按该次快照授权。
