## 已实现链条

- 服务端：SQLite WAL / 唯一约束 / 串行事务与嵌套上下文；显式初始化、禁止重复初始化重置密码；scrypt 密码与散列会话令牌，8h HTTP-only SameSite Strict Cookie，CSRF / Origin 边界和基础登录限流。
- 授权：服务端从会话取得 Actor 和时钟；读取方法及命令字段白名单；学生本人、企业已获授权投递快照、辅导员辖区、管理员脱敏审计各自隔离。管理员启停立即撤会话，改密与退出竞态已修。
- 业务：真实 HTTP 完成投递→面试→录用→双方协议确认→去向提交→辖区审核；事务失败不留半写入，幂等命令重试不重复，旧 revision 拒绝覆盖，重启后数据保留。
- 前端：同源 HTTP 仓储、会话恢复、登录回跳与角色守卫；在线不建浏览器业务种子，不开放演示角色模拟、全库复位、本人硬删除或本机 LIVE 网关。
- 工作区：收藏持久化、用户归属通知与已读、动态待办、候选筛选/排序、名册审核状态/专业/届别筛选，学生查看带明确时区的面试安排。
- 同步与失败：SSE 仅对当前授权账号发送空变更信号，重连授权重读；失效断流后退出。简历与去向外部刷新不覆盖脏草稿，409 保留输入；断网保存明确失败，未保存输入保留在当前页面。
- 图片：四角色本人私有工作区图片支持预览/保存/移除，服务端实际解码、2MiB / 12MP / 单帧 / 最小尺寸限制、512 方图 JPEG 重编码和去元数据，归属与 revision 约束。非公开头像或组织商标管理。
- 视觉：共同门户、公开岗位与服务入口；原创稳定企业标识贯穿岗位/推荐/投递/协议/企业页。评分环字号、控件拉伸、搜索/名册边框、企业紧凑子页与小屏布局修整；精简重复小字，保留必要授权、隐私、AI 来源和恢复说明。

## 本轮发现与修复详情

- 重复初始化原可覆盖密码：真实 CLI 子进程测试先失败后通过，原账号密码保留。
- 改密中的旧密码登录和退出落在无关回滚中的竞态：真实 SQLite 测试先失败后通过，凭据重读与会话增删串行化。
- 去向旧草稿被外部更新覆盖：双页 HTTP 测试先失败后通过，分离 draftId/revision 与不可变提交快照。
- 模拟面试提交期间仍能编辑下一题、随后被清空：延迟真实 HTTP 回包测试先失败后通过，提交时锁输入。
- 门户图片回退测试最初没有证明首选图片被请求，存在假绿：补首选请求证据后看到失败，再接首选与回退；另验双图失败只请求两次，不循环并保留布局。
- 375px 标题末字落单与 768px 名册挤压详情：布局测试先失败，修复后通过。
- 企业紧凑子页继承横幅浅色字，浅色主题对比不足：实际截图发现，computed color 回归先失败，修复文字语义与装饰继承后通过。
- 企业筛选后右栏仍显示已被筛掉的候选人：实际交互发现，先失败再改为只从过滤结果选择；筛选为空时不残留旧详情，避免对错误对象操作。
- 全量旧用例曾误匹配新增 select 中的隐藏 option：将断言限定实际详情区域；辅导员1初始辖区全已通过，使用真实 10 人状态和待审核空态，不篡改种子迎合测试。
